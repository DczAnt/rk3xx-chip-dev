# RK3562 芯片能力描述

> SoC: RK3562 | 架构: aarch64 (Cortex-A53 ×4 @1.8GHz)
> RK3562 是 RK3568 的低成本简化版，NPU 单核，常用于轻量 IPC/网关。

## 硬件加速器

| 模块 | 能力 |
|------|------|
| rkvdec | 硬解 H.264/H.265/VP9/AV1 |
| rkvenc | 硬编 H.264/H.265 |
| RGA | 2D 加速（单实例） |
| NPU | RKNPU **单核** 0.8 TOPS INT8 |

## NPU 能力

- **核心数**: 1（单核）
- **core_mask**: 仅 `NPU_CORE_AUTO`/`NPU_CORE_0` 有效
- **rknnrt**: `librknnrt.so`（与 RK3568 相同，aarch64）
- **量化类型**: INT8/FP16

## 与 RK3568 差异

| 维度 | RK3562 | RK3568 |
|------|--------|--------|
| CPU | A53 ×4 @1.8GHz | A55 ×4 @2.0GHz |
| NPU | 单核 0.8T | 单核 0.8-1T |
| VPU JPEG | ✓（有 jpege） | ✗（无 jpege） |
| PCIe | PCIe 2.1 | PCIe 3.0 |
| 场景 | 轻量 IPC/网关 | 主板级应用 |

## model zoo 支持

RK3562 被 `rknn_model_zoo` 完整支持（所有 27 个模型）。
见 `references/rknn-model-zoo.md`。

## 典型 OS / glibc

- Buildroot / Debian / glibc 2.31-2.34 / 内核 5.10.x
- 交叉编译: `aarch64-linux-gnu-gcc`

## 编译方式

- **交叉编译**: `aarch64-linux-gnu-gcc`，与 RK3568 相同工具链
- **Rust**: `aarch64-unknown-linux-gnu` 或 musl 静态

# RV1106 芯片能力描述

> SoC: RV1106 | 架构: **armhf** (Cortex-A7 ×1 @1.2GHz, 32位)
> RV1106 是 RV11xx 系列低成本视觉芯片，常用于 IPC 摄像头模组。

## 硬件加速器

| 模块 | 能力 |
|------|------|
| rkvdec | 硬解 H.264/H.265 |
| rkvenc | 硬编 H.264/H.265 |
| RGA | 2D 加速（轻量版） |
| NPU | RKNPU **单核** 0.5-1 TOPS INT8（轻量版） |

## NPU 能力

- **核心数**: 1（单核）
- **core_mask**: 仅 `NPU_CORE_AUTO`/`NPU_CORE_0` 有效
- **rknnrt**: 使用 `librknnmrt.so`（**注意：mrt 后缀**，与 RK35xx 系列的 `librknnrt.so` 不同）
- **量化类型**: INT8

## 架构差异（关键）

- **32 位 ARM (armhf)**: 交叉编译目标 `arm-unknown-linux-gnueabihf`，**非 aarch64**
- **内存限制**: 通常 64-256MB DDR3，需严格控制内存占用
- **无 PCIe/SATA/USB3**: 仅 USB2/SDIO/SPI，外设带宽有限

## SDK 路径

- RKNN 头文件: `/usr/include/rknn_api.h`
- librknnmrt.so: `/usr/lib/`（注意 `mrt` 后缀）
- 链接时: `-lrknnmrt`（非 `-lrknnrt`）

## 典型 OS / glibc

- Buildroot / Yocto 精简 Linux / glibc 2.31-2.34 / 内核 5.10.x
- **交叉编译**: 必须用芯片厂商提供的工具链（Rockchip RV1106 SDK 内置）

## 编译方式

- **必须交叉编译**: 板上无 gcc，用 RV1106 SDK 工具链 `arm-rockchip830-linux-uclibcgnueabihf-gcc`
- **注意**: uclibc 而非 glibc（部分 RV1106 版本），链接方式不同
- **Rust**: `armv7-unknown-linux-gnueabihf` target
- **Go**: `GOARM=7 GOARCH=arm`

## 与 RK35xx 系列差异

| 维度 | RV1106 | RK3568 |
|------|--------|--------|
| 架构 | armhf (32位) | aarch64 (64位) |
| NPU 库 | librknnmrt.so | librknnrt.so |
| 内存 | 64-256MB | 2-8GB |
| 工具链 | arm-rockchip830-...-uclibcgnueabihf | aarch64-linux-gnu |
| 场景 | IPC 模组 | 主板级应用 |

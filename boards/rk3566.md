# RK3566 芯片能力描述

> SoC: RK3566 | 架构: aarch64 (ARMv8, Cortex-A55 ×4 @1.8GHz)
> RK3566 是 RK3568 的低成本裁切版，NPU/RGA/MPP 能力基本一致。

## 硬件加速器

| 模块 | 能力 |
|------|------|
| VDPU2 | 硬解 H.264/H.265/VP9/AV1 |
| VEPU2 | 硬编 H.264/H.265 |
| RGA2 | 2D 加速（单实例），stride 16 字节对齐 |
| NPU | RKNPU2-LITE **单核** 0.8 TOPS INT8 |

## NPU 能力

- 与 RK3568 相同：单核，`core_mask` 仅 `NPU_CORE_AUTO`/`NPU_CORE_0` 有效
- **板载模型路径**: `/usr/share/model/RK3566_RK3568/`（RK3566 与 RK3568 共用模型）

## SDK 路径

- 与 RK3568 基本一致，头文件/库路径相同
- `rknn-toolkit2` 转换时 `target_platform='rk3566'` 或 `'rk3568'` 均可（同模型）

## 与 RK3568 差异

| 维度 | RK3566 | RK3568 |
|------|--------|--------|
| CPU 频率 | 1.8GHz | 2.0GHz |
| PCIe | 无 PCIe 3.0 | 有 |
| SATA | 无 | 有 SATA 3.0 |
| NPU/RGA/MPP | 相同 | 相同 |

## 编译方式

- Docker 交叉编译，与 RK3568 共用工具链和 SDK

# RK3568 芯片能力描述

> SoC: RK3568 | 架构: aarch64 (ARMv8, Cortex-A55 ×4 @2.0GHz)
> 本文件描述芯片**能力**，不绑定具体板子 IP/密码（见 `registry.yaml`）。

## 硬件加速器

| 模块 | 设备节点 | 能力 |
|------|---------|------|
| VDPU2 | `/dev/mpp_service` (vdpu) | 硬解 H.264/H.265/VP9/AV1/MPEG-1/2/4/H.263 |
| VEPU2 | `/dev/mpp_service` (vepu) | 硬编 H.264/H.265/VP8/MJPEG |
| JPEGdec | `/dev/mpp_service` (jpegd) | JPEG 硬解 |
| RGA2 | `/dev/rga` | 2D 缩放/旋转/格式转换/裁剪，stride 需 16 字节对齐 |
| NPU | `/dev/rknpu` | RKNPU2-LITE **单核** 0.8 TOPS INT8 |

## NPU 能力（关键差异点）

- **核心数**: 1（单核）
- **core_mask 有效值**: `NPU_CORE_AUTO`(0) / `NPU_CORE_0`(1)
- **无效值**: `NPU_CORE_1` / `NPU_CORE_0_1`（单核芯片不支持，设了也只跑 Core0）
- **量化类型**: INT8
- **rknnrt 版本**: 2.3.x
- **负载查询**: `cat /sys/kernel/debug/rknpu/load`

## RGA 能力

- **实例数**: 1（单 RGA2）
- **不支持**: `im_opt_t.core` 双实例调度（单实例芯片无意义）
- **支持格式**: NV12/NV16/RGB888/BGR888/RGBA8888 等
- **stride 对齐**: 16 字节

## VPU JPEG

- **硬编**: 通过 MPP `MPP_VIDEO_CodingMJPEG`，**无** ffmpeg-rockchip `mjpeg_rkmpp` 编码器（RK3568 VPU 不含 jpege）
- **硬解**: JPEGdec 模块可用

## DRM/VOP2

- **plane 数量**: HDMI VP0 通常 3 个（Smart/Esmart/Cluster）
- **Cluster plane**: 仅支持 AFBC，**不支持 LINEAR dumb buffer**（SetPlane 返回 -22）
- **可用 plane**: Smart1-win0 (XRGB8888 Primary) + Esmart1-win0 (ARGB8888 Overlay)
- **多路独立 NV12 直显**: 不支持（plane 不足），需 RGA 合成到单 plane

## SDK 路径（板上）

| 组件 | 路径 |
|------|------|
| MPP 头文件 | `/usr/include/rockchip/` |
| RKNN 头文件 | `/usr/include/rknn_api.h` |
| RGA 头文件 | `/usr/include/rga/` |
| librockchip_mpp.so | `/usr/lib/aarch64-linux-gnu/` |
| librknnrt.so | `/usr/lib/aarch64-linux-gnu/` |
| librga.so / librga.a | `/usr/lib/aarch64-linux-gnu/` |
| ffmpeg-rockchip | `/usr/local/bin/ffmpeg`（若已编译安装） |

## 典型 OS / glibc

- Ubuntu 20.04 / glibc 2.31 / 内核 5.10.x
- **交叉编译注意**: 容器 glibc 2.35 vs 板子 glibc 2.31，动态链接需板子 crt 方案（见 `knowledge/cross-compile-glibc.md`）

## 编译方式

- **推荐**: Docker 交叉编译（aarch64-linux-gnu-gcc 11.4）
- **板上原生编译**: 可行但慢（Cortex-A55 算力有限），不推荐大型项目

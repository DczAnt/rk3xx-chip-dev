# RK3576 芯片能力描述

> SoC: RK3576 | 架构: aarch64 (ARMv8, big.LITTLE: A53×4 @1.4GHz + A72×4 @1.6GHz)

## 硬件加速器

| 模块 | 能力 |
|------|------|
| rkvdec | 硬解 H.264/H.265/VP9/AV1 |
| rkvenc ×2 | **双核**硬编 H.264/H.265 |
| jpege | **JPEG 硬编**（VPU 含 jpege，`mjpeg_rkmpp` 可用） |
| jpegd | JPEG 硬解 |
| RGA2 ×2 | **双实例** 2D 加速 (scheduler[0] + scheduler[1]) |
| NPU ×2 | **双核** 850MHz，RKNPU v0.9.8，rknnrt v2.3.2 |
| VOP2 | 显示控制器，HDMI 3840×2160@60 |

## NPU 能力（关键差异点）

- **核心数**: 2（双核）
- **core_mask 有效值**: `NPU_CORE_AUTO`(0) / `NPU_CORE_0`(1) / `NPU_CORE_1`(2) / `NPU_CORE_0_1`(3)
- **双核并行正确用法**: 创建 **2 个独立 RKNN context**，分别 `rknn_set_core_mask(ctx0, CORE_0)` 和 `rknn_set_core_mask(ctx1, CORE_1)`，配合 2 个推理线程
- **错误用法**: 单 context 设 `CORE_0_1` 无效（Core1 仍 0%）
- **量化类型**: INT8

## RGA 能力

- **实例数**: 2（双 RGA2）
- **双实例调度**: `im_opt_t.core` 字段指定 scheduler
  - `IM_SCHEDULER_RGA2_CORE0 = 1<<2 = 4` → scheduler[0]
  - `IM_SCHEDULER_RGA2_CORE1 = 1<<3 = 8` → scheduler[1]
- **注意**: `im_opt_t` 参数需用 **C++ 版 `improcess`（10 参数版）**，C 版无此参数

## VPU JPEG 硬编

- **可用**: `mjpeg_rkmpp` 编码器（VPU 含 jpege）
- **输入格式限制**: **必须 `AV_PIX_FMT_NV12` + 软件帧**，不接受 `AV_PIX_FMT_DRM_PRIME`（报 "Unsupported input pixel format"）
- **流程**: mmap DMA-BUF → memcpy NV12 → AVFrame → mjpeg_rkmpp → JPEG
- **收益**: 消除 sws_scale 色彩转换 + CPU MJPEG 编码，VPU 硬件执行

## CPU big.LITTLE 绑核

| 核心范围 | 架构 | 频率 | 适合 |
|---------|------|------|------|
| CPU0-3 | Cortex-A53 | 408-1416 MHz | I/O 密集（解码、网络） |
| CPU4-7 | Cortex-A72 | 408-1608 MHz | 计算密集（推理、后处理） |

```c
#define _GNU_SOURCE
#include <sched.h>
#include <pthread.h>
// 解码线程 → A53 小核
cpu_set_t dec_set; CPU_ZERO(&dec_set);
for (int i = 0; i < 4; i++) CPU_SET(i, &dec_set);
pthread_setaffinity_np(dec_tid, sizeof(cpu_set_t), &dec_set);
// 推理线程 → A72 大核
cpu_set_t inf_set; CPU_ZERO(&inf_set);
for (int i = 4; i < 8; i++) CPU_SET(i, &inf_set);
pthread_setaffinity_np(inf_tid, sizeof(cpu_set_t), &inf_set);
```

## DRM/VOP2

- **plane ID**: 与 RK3568 不同（如 108/148 vs 57/129），**代码应自动探测** Smart/Esmart plane，不要硬编码 ID
- **HDMI**: 3840×2160@60
- **Video plane**: XRGB8888, zpos=0
- **OSD plane**: ARGB8888 alpha blend, zpos=1

## SDK 路径（板上）

| 组件 | 路径 |
|------|------|
| MPP 头文件 | `/usr/include/rockchip/` |
| RKNN 头文件 | `/usr/include/rknn/rknn_api.h`（注意多一层 `rknn/` 目录） |
| RGA 头文件 | `/usr/include/rga/`（含 `im_opt_t`, `IM_SCHEDULER_RGA2_*`） |
| librknnrt.so | `/lib/librknnrt.so`（注意：可能在 `/lib/` 而非 `/usr/lib/`） |
| ffmpeg-rockchip 静态库 | `/opt/ffmpeg-build/lib/`（**非** `/usr/local/lib/`） |
| ffmpeg-rockchip 头文件 | `/opt/ffmpeg-build/include/` |
| ffmpeg 可执行 | `/opt/ffmpeg-build/bin/ffmpeg` |

**路径差异（vs RK3568）**: ffmpeg 静态库、RKNN 头文件位置不同，编译脚本需按板子能力描述选择路径。

## 典型 OS / glibc

- Ubuntu 22.04 / glibc 2.35 / 内核 6.1.x
- **交叉编译**: 容器与板子 glibc 一致（均 2.35），**无需板子 crt 方案**，直接动态链接即可

## 编译方式

- **板上原生编译**: gcc 11.4.0 + glibc 2.35，直接 `g++` 编译，**无需 Docker**
- **生产部署**: 推荐 Docker 交叉编译，板端只放 strip 后二进制（防源码拉取）
